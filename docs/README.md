# Base de Conocimiento — EduÉtica

Esta carpeta está destinada a almacenar archivos **PDF** que servirán como base de conocimiento para el sistema de IA.

## Uso previsto

Los documentos PDF aquí almacenados podrán ser:
1. **Procesados por Gemini AI** para enriquecer el contexto de los dilemas generados
2. **Indexados** para responder preguntas en el módulo de chat
3. **Referenciados** para verificar la corrección de las respuestas de los estudiantes

## Ejemplos de documentos recomendados

- Manual de ética aplicada para jóvenes
- Guía de dilemas éticos por nivel educativo
- Material curricular por tema:
  - `cambio-climatico.pdf`
  - `derechos-animales.pdf`
  - `corrupcion.pdf`
  - `eutanasia.pdf`
  - `aborto.pdf`
  - `pena-de-muerte.pdf`
  - `ciberacoso.pdf`

## Formatos aceptados

- PDF (recomendado)
- TXT
- Markdown (.md)

> **Nota**: Esta carpeta es solo de almacenamiento local. La integración con la API de IA se realizará en la Fase 2 del proyecto.
